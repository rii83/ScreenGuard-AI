ScreenGuard AI

About the Project

ScreenGuard AI is a simple AI project that uses a camera to detect people in real time. It uses YOLO to analyze the camera feed, count detected people, and display the current security status.

Features

Real-time person detection.

People counting.

Security status display.

Desktop notifications when an alert is triggered.

Technologies

Python

OpenCV

YOLO

Disclaimer

ScreenGuard AI is an educational prototype. It detects people and counts them, but it cannot identify individuals or determine whether they are authorized. Its alerts are based on the number of people detected and may not always be accurate.
